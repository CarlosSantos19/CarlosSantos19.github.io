# carlossantos19.github.io

Sitio raíz de GitHub Pages para **RedCity** (la app está en el repositorio [RedCity](https://github.com/CarlosSantos19/RedCity) y se publica en `/RedCity/`).

- `.well-known/assetlinks.json`: verificación de Google (Digital Asset Links) para que la app de Android de Play Store abra RedCity sin la barra del navegador. Se completa con la huella SHA-256 de la firma de la app.
- `.nojekyll`: evita que GitHub Pages oculte la carpeta `.well-known`.
- `index.html`: redirige a `/RedCity/`.
